\subsection*{Summary}
This manuscript presents a novel hybrid architecture that combines a Neural Koopman Operator with a Physics-Informed Graph Neural Network (NeKo-PIGNN) for real-time wildfire propagation modeling. The key innovations are:

\begin{enumerate}
  \item \textbf{Neural Koopman Operator}: Linearizes the nonlinear fire dynamics into a latent space, enabling stable long-term predictions ($t+6$ to $t+72$ hours) via a learned Koopman matrix $K$.

  \item \textbf{Physics-Informed GNN}: Propagates fire state between neighboring municipalities using graph message passing, regularized with the Rothermel fire spread equation as a PDE residual loss.

  \item \textbf{Causal Simulation}: A differentiable causal intervention mechanism (``what-if'' analysis) allowing land managers to query the effect of changing wind, humidity, or vegetation.
\end{enumerate}

\subsection*{Contributions}
\begin{itemize}
  \item First published combination of Neural Koopman Operators with Physics-Informed GNNs for wildfire modeling (zero prior publications in this specific intersection).
  \item Complete open-source digital twin pipeline: GOES-16/VIIRS ingestion $\rightarrow$ Koopman encoding $\rightarrow$ GNN propagation $\rightarrow$ dashboard.
  \item Validation against 184 municipalities in Ceará, Brazil, with ablation studies confirming the hybrid model outperforms both pure-Koopman (F1=0.82), pure-PINN (F1=0.79), and standard baselines (CNN, GNN, Neural ODE).
  \item Fully reproducible code available on GitHub.
\end{itemize}

\subsection*{Novelty Statement}
To the best of our knowledge, this is the first work to combine Neural Koopman Operators with Physics-Informed Graph Neural Networks for real-time wildfire digital twins. While Koopman theory has been applied to fluid dynamics and GNNs to fire detection, no existing publication unifies these approaches with differentiable Rothermel physics for operational fire prediction.
